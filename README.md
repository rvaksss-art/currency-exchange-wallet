# Прототип Кошелька

## Назначение

Проект описывает создание заявки на обмен валют между счетами внутреннего кошелька. Он включает требования, историю промптов, интерактивный HTML-прототип и комплект аналитической документации.

Актуальная версия прототипа — `test6 - CODEX.html`. Предыдущие HTML-файлы сохранены как история итераций.

## Состав проекта

- `Практическое_тестовое_задание_Бизнес_аналитик.docx` — исходное задание;
- `1. requirements.md` — требования, правила и сценарии;
- `2. promt-OpenDesign.md` и файлы `2.1`–`2.4` — цепочка промптов OpenDesign;
- `test1.html`–`test5 - FINAL.html` — предыдущие версии прототипа;
- `test6 - CODEX.html` — исправленная интерактивная версия;
- [SDD.md](SDD.md) — системный дизайн;
- [scenarios.feature](scenarios.feature) — приёмочные сценарии Gherkin;
- [openapi.yaml](openapi.yaml) — контракт будущего API OpenAPI 3.1;
- `0.5. project plan.md` — план выполнения задания.

## Как открыть прототип

Откройте `test6 - CODEX.html` в современном браузере. Прототип не требует сборки, установки зависимостей или подключения к серверу.

Для основной демонстрации:

1. Введите `10 000` RUB.
2. Проверьте результат `107,68 USDT`, комиссию `50,00 RUB` и таймер 30 секунд.
3. Нажмите «Обменять».
4. Проверьте экран результата и обновлённые балансы.
5. Нажмите «Вернуться в кошелёк».

## Демонстрационные состояния

| Состояние | Как воспроизвести |
| --- | --- |
| Основной экран | Открыть HTML без параметров |
| Выполненный расчёт | Ввести положительную сумму либо открыть `?scenario=calculated` |
| Недостаточно средств | Ввести `60 000` RUB либо открыть `?scenario=insufficient` |
| Курс истёк | Подождать 30 секунд либо открыть `?scenario=expired`, затем нажать «Обновить курс» |
| Курс изменился | Открыть `?scenario=rate-change`, нажать «Обменять» |
| Операция отклонена | Открыть `?scenario=declined`, нажать «Обменять» |
| Список валют | Нажать «Открыть все» |

URL-параметр добавляется к пути файла, например `test6%20-%20CODEX.html?scenario=rate-change`.

## Тестовые значения

- начальный баланс: `50 000,00 RUB` и `250,40 USDT`;
- курс: `1 USDT = 92,40 RUB`;
- комиссия RUB → USDT: `50,00 RUB`;
- обмен `10 000,00 RUB` даёт `107,68 USDT`;
- комиссия USDT → RUB при этом курсе: `0,54 USDT`;
- обмен `100,00 USDT` даёт `9 190,10 RUB`;
- изменённый курс: `1 USDT = 92,65 RUB`;
- срок действия котировки: 30 секунд.

## Ограничения прототипа

Прототип использует mock-данные и локальное состояние JavaScript. Он не вызывает настоящий API, не аутентифицирует пользователя, не сохраняет заявки и котировки после перезагрузки, не обеспечивает серверную идемпотентность, транзакционную атомарность или аудит.

В HTML реально работают ввод, локальный расчёт, проверка баланса и формата, смена направления, таймер котировки, блокировка истёкшего курса, выпуск новой mock-котировки, демонстрация изменения курса, обновление локальных балансов, результат операции и окно списка валют.

На уровне документации описаны будущие серверные функции: повторная проверка баланса, уникальные `quoteId` и `orderId`, ключ `Idempotency-Key`, хранение статусов, атомарное изменение балансов, аудит и обработка отказов внешних сервисов.

## Использование ИИ

OpenDesign использовался для разработки и последовательного уточнения UX/UI-концепции. История исходного промпта и четырёх итераций сохранена в проекте.

Codex использовался для анализа требований и прототипа, проверки расчётов, исправления HTML-логики и подготовки SDD, Gherkin, OpenAPI и README. В частности, вручную зафиксированы и исправлены ошибка масштаба в расчёте USDT → RUB, автоматическое продление истёкшей котировки, отсутствующая SVG-иконка и неверный символ USDT.

# Конвертер валют / прототип кошелька

## Назначение

Проект описывает создание заявки на обмен валют между счетами внутреннего кошелька. Он включает требования, историю промптов, интерактивный HTML-прототип и комплект аналитической документации.

Актуальная версия интерфейса — `index.html` (он же `test6 - CODEX.html`). Предыдущие HTML-файлы сохранены как история итераций. Для сохранения балансов и заявок запускайте локальный сервер `server.py`: он использует SQLite из стандартной библиотеки Python.

## Запуск приложения с базой SQLite

Нужен Python 3.10 или новее. В каталоге проекта запустите:

```powershell
python server.py
```

Откройте <http://127.0.0.1:8000>. Сторонние пакеты не нужны. При первом запуске создаётся `data/wallet.sqlite3` с демонстрационными балансами. Дальнейшие обмены сохраняются в этой базе и остаются после перезапуска сервера. Чтобы сбросить демонстрационную базу, остановите сервер и выполните `python server.py --reset-db`.

Сервер слушает только локальный адрес `127.0.0.1`. Это однопользовательская демонстрация без авторизации; её нельзя выставлять в интернет или использовать для реальных денег.

Можно открыть `test6 - CODEX.html` напрямую как автономный mock-прототип, но в таком режиме данные хранятся только в памяти вкладки и SQLite не используется.

Для основной демонстрации:

1. Введите `10 000` RUB.
2. Проверьте результат `107,68 USDT`, комиссию `50,00 RUB` и таймер 30 секунд.
3. Нажмите «Обменять».
4. Проверьте экран результата и обновлённые балансы.
5. Нажмите «Вернуться в кошелёк».

## Демонстрационные состояния

| Состояние | Как воспроизвести |
| --- | --- |
| Основной экран | Открыть HTML без параметров |
| Выполненный расчёт | Ввести положительную сумму либо открыть `?scenario=calculated` |
| Недостаточно средств | Ввести `60 000` RUB либо открыть `?scenario=insufficient` |
| Курс истёк | Подождать 30 секунд либо открыть `?scenario=expired`, затем нажать «Обновить курс» |
| Курс изменился | Открыть `?scenario=rate-change`, нажать «Обменять» |
| Операция отклонена | Открыть `?scenario=declined`, нажать «Обменять» |
| Список валют | Нажать «Открыть все» |

URL-параметр добавляется к пути файла, например `test6%20-%20CODEX.html?scenario=rate-change`.

## Тестовые значения

- начальный баланс: `50 000,00 RUB` и `250,40 USDT`;
- курс: `1 USDT = 92,40 RUB`;
- комиссия RUB → USDT: `50,00 RUB`;
- обмен `10 000,00 RUB` даёт `107,68 USDT`;
- комиссия USDT → RUB при этом курсе: `0,54 USDT`;
- обмен `100,00 USDT` даёт `9 190,10 RUB`;
- изменённый курс: `1 USDT = 92,65 RUB`;
- срок действия котировки: 30 секунд.

## Реализация и ограничения

Локальный режим сервера предоставляет `GET /api/v1/wallet`, `GET /api/v1/exchange-orders` и `POST /api/v1/exchange-orders`. Сервер повторно проверяет баланс, рассчитывает комиссию и сумму зачисления в целых минимальных единицах, атомарно меняет оба баланса и сохраняет заявку. `Idempotency-Key` защищает повторный запрос от повторного списания; тот же ключ с другим телом получает `409`.

Курс и условия остаются демонстрационными: `1 USDT = 92,40 RUB`, фиксированная комиссия 50 RUB, один локальный кошелёк и пять тестовых валют. Нет авторизации, реального поставщика курса, API котировок, внешнего исполнения, аудита или защиты от локального владельца компьютера. `openapi.yaml` описывает целевой контракт и не полностью совпадает с текущим локальным API.

Открытие HTML напрямую сохраняет прежний автономный mock-режим для демонстрации таймера котировки, отказа и изменения курса.

## Использование ИИ

OpenDesign использовался для разработки и последовательного уточнения UX/UI-концепции. История исходного промпта и четырёх итераций сохранена в проекте.

Codex использовался для анализа требований и прототипа, проверки расчётов, исправления HTML-логики и подготовки SDD, Gherkin, OpenAPI и README. В частности, вручную зафиксированы и исправлены ошибка масштаба в расчёте USDT → RUB, автоматическое продление истёкшей котировки, отсутствующая SVG-иконка и неверный символ USDT.
